# GLOBAL SERVICE – GÉNIE CIVIL (BTP · BÉNIN)

> **« CONSTRUIRE AUJOURD'HUI, BÂTIR LE FUTUR »**  
> Site web haut de gamme, immersif et responsive pour l'entreprise béninoise de BTP et de Génie Civil.

---

## 🏗️ Architecture & Technologies

- **Frontend Core :** React 18 + TypeScript + Vite
- **Styling & Design System :** Tailwind CSS + Lucide Icons + Google Fonts (Sora & Manrope)
- **Expérience 3D & Motion :** Three.js + React Three Fiber + Drei + GSAP + Framer Motion
- **Défilement Fluide :** Lenis Smooth Scrolling
- **Effets Graphiques :** 3D Tilt interactif sur cartes, Canvas Confetti sur conversion, Blueprint architectural
- **Photographies Authentiques :** 71 images haute définition d'ingénierie et de chantiers en Afrique de l'Ouest
- **Branding & Logo :** Monogramme vectoriel "GS" architectural original (formats SVG horizontal, vertical et icône)
- **Localisation & Contact :** Intégration Google Maps (Place ID : `ChIJY3h3grxVIxARnoC6CpHoBWI`) et passerelle WhatsApp dynamique

## 🚀 Démarrage Rapide

```bash
# 1. Installation des dépendances
npm install

# 2. Lancement du serveur de développement
npm run dev

# 3. Construction pour la production
npm run build
```

Le serveur local est disponible sur : **http://127.0.0.1:3000/**

## 📐 Sections & Fonctionnalités Intégrées

1. **Header Glassmorphic :** Navigation transparente avec flou d'arrière-plan, menu mobile fluide, indicateur en direct du bureau d'études.
2. **Hero Immersif 3D :** Scène 3D interactive représentant une tour contemporaine avec grue rotative, grille blueprint et bascule « Mode Structure BIM / Rendu Réaliste ».
3. **À Propos de Global Service :** Vision, mission, valeurs, rigueur géotechnique béninoise et composition photographique africaine.
4. **Services & Expertises :** Cartes 3D Tilt avec filtres thématiques, fiches détaillées et déclenchement de devis pré-rempli.
5. **Réalisations & Chantiers :** Portfolio filtrable avec statuts des projets (Livré, En cours, Validé), fiches techniques et galerie photo.
6. **Nos Engagements (HSE) :** Les 4 piliers d'exigence (Rigueur dimensionnelle, Sécurité zéro accident, Contrôle laboratoire 28j, Respect des délais).
7. **Équipes & Direction :** Ingénieurs structures, géotechniciens et chefs de projet béninois.
8. **Actualités Techniques :** Publications sur la géotechnique côtière, le BIM et l'assainissement pluvial.
9. **Conversion & Contact :** Formulaire de devis interactif avec confetti de validation, génération automatique de messages préremplis sur WhatsApp et intégration Google Maps.
10. **Bouton Flottant WhatsApp :** Accès direct avec notification visuelle et message contextuel.
